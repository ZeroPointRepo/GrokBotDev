## What it does

Runs supervision for batches of cloud-based agent jobs from a single seat: kicks them off, watches how they progress, hounds whatever stalls and rolls the whole batch up into one summary report. Instead of babysitting each run in its own tab, you get exceptions and a roll-up. It is built as a team of bots rather than a single one, so the roles stay separate.
