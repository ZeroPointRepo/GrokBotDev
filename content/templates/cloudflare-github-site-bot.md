## What it does

A walkthrough for getting a website live on GitHub and Cloudflare Workers, whether you are starting fresh or migrating something that already exists. It covers the whole path from accounts that do not exist yet, past SSH keys and API tokens, on to the deploy itself — the fiddly credential steps stop sinking launches. It runs when you ask it to, rather than on a timer.
