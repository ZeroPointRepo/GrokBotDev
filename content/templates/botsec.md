## What it does

In a home running several assistants, this one acts as head of security. A person or bot checks in before opening a link from an untrusted source, and it sweeps a Gmail account for phishing tells while reading message headers. Each domain, URL and file hash is screened through reputable open-source checkers. It runs when you ask it to, rather than on a timer. It is built as a team of bots rather than a single one, so the roles stay separate.
