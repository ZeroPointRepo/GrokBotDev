## What it does

A bot's configuration and everything it has learned sit inside the account, with no obvious way to get them back once something breaks. This one copies both out to a private repository on a fixed folder layout, keeps a register of what it holds, and revisits the set to catch gaps. A whole fleet can be rebuilt from it. It is built as a team of bots rather than a single one, so the roles stay separate.

## Before you install

Open the share link and read the instructions it carries before you add it. @AYi_AInotes shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
