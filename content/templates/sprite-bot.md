## What it does

Give it a written description or a picture and it produces a 2D character with the animations a side-scroller actually needs: walking, jumping, attacking. Output is checked before it arrives and comes out ready for Unity, Godot, or a plain GIF, so the asset drops into a project without cleanup. It runs when you ask it to, rather than on a timer.
