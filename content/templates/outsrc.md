## What it does

A local dispatcher that farms your bot's programming work out to the command-line coding agents you already pay for, naming Claude Code, Codex and xAI's Grok Build among them. Every job runs in a fresh git worktree so nothing collides, and the result returns as a diff you review before keeping it.

## Before you install

Open the share link and read the instructions it carries before you add it. @edtadros shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
