## What it does

Agent Looper starts a coding loop on the computer you add it to. You freeze a goal, it uses a determined check, and it starts a fresh worker every round instead of keeping one session warm. It drives Cursor, Cline, OpenCode, Pi, Codex, or DSH only when that harness is already installed. It does not provision servers or ask you to paste keys into the listing.

## Before you install

You need a coding harness already on your machine. Open the share link and read the instructions it carries before you add it. Adding copies the setup into your own Grok Bot. It runs on your computer with your own keys.
