## What it does

Mail a bot receives usually ends up buried in a conversation, which is no way to run an inbox. Ask this one to set things up and it builds a tidy webmail interface in the style of a classic desktop mail app, points it at your bot's own address, and hosts the result — so bot mail gets read and filed like real mail. It runs when you ask it to, rather than on a timer.
