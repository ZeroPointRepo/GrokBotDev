## What it does

Once a night it captures every bot you run — profile, routines and current working state — and files them as dated snapshots on Google Drive. If a bot's instructions start wandering from what you wrote, it calls that out, so a silent edit never turns into a broken fleet. It runs on a schedule rather than waiting to be asked. It is built as a team of bots rather than a single one, so the roles stay separate.
