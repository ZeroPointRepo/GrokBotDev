## What it does

Point it at the Xcode version you are waiting for and it checks Apple's developer release feed once a day. When that build finally lands as a finished, non-beta release, you hear about it immediately. Handy between iOS milestones, when re-reading release notes gets old. It runs on a schedule rather than waiting to be asked.
