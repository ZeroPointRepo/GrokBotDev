## What it does

An odd and useful relay: a Grok bot whose output is meant for another tool entirely. It returns tight PLAN or REVIEW blocks sized to paste into a Cursor cloud coding agent, with none of the usual chat padding around them. Handy when a second model's read on a plan is wanted before code gets written. It runs when you ask it to, rather than on a timer.
