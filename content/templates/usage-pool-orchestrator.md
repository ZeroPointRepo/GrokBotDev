## What it does

This one stays deliberately small: rather than doing the engineering itself, it passes each job out to a command-line coding tool you already pay for. Cursor is the standard target, with Grok Build, Claude Code and Codex offered as alternatives, so the metering lands on whichever quota you would rather spend down. It runs when you ask it to, rather than on a timer.
