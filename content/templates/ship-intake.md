## What it does

A bug reported in Slack becomes a properly written GitHub issue, gets handed to a Cursor cloud agent for the fix, and the outcome lands back in the original thread so the reporter hears what happened. The loop closes where it started, with a human still reading along. The author's team runs it daily. It runs when you ask it to, rather than on a timer.
