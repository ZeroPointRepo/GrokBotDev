## What it does

Each weekday morning it sweeps the repositories you name for pull requests, issues and comment threads that appeared since the last look, then lands everything in a single digest. Every open PR gets a priority read on how much attention it actually needs, so the review queue starts sorted instead of overwhelming. It runs on a schedule rather than waiting to be asked.

## Before you install

Open the share link and read the instructions it carries before you add it. @MichaelGannotti shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
