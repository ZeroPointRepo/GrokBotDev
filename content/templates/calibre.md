## What it does

Send it a book, say which format you need it in, and the rebuilt file comes back to you in the conversation. It stands up the open-source Calibre toolchain itself, so there is no desktop application to install, no settings panel to learn, and nothing has to be uploaded to some third-party conversion site along the way. It runs when you ask it to, rather than on a timer.

## Before you install

Open the share link and read the instructions it carries before you add it. @doitian shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
