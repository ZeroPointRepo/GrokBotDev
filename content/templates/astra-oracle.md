## What it does

Works a layer up from your Cursor cloud coding agent and owns the thinking rather than the typing: running a GPT-6 Astra session inside Codex CLI, it produces structured PLAN and REVIEW packets for the implementer. Writing code is the one thing it will not do, which keeps the planner and builder roles separate. It is built as a team of bots rather than a single one, so the roles stay separate.
