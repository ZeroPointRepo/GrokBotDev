## What it does

Wraps a command-line build harness in a bot, so app work, coding and deep-research jobs can run hard on a hosted agent machine instead of occupying your own terminal. Useful when a task needs to run long or unattended and you would rather not keep a session open. Tooling only: nothing spends money. It runs when you ask it to, rather than on a timer.
