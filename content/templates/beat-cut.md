## What it does

Hand it an audio file and it produces a video whose cuts land exactly on the beat. If you have no track ready, it can compose a beat first and edit to its own rhythm instead. The frame-accurate slicing is done in plain code rather than through a model, which keeps token use and API spending low even on longer songs. It runs when you ask it to, rather than on a timer.
