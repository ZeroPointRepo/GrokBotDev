## What it does

Point it at a frontend, interface or architecture job and it drives Anthropic's Claude Code CLI on your behalf, running Opus unless told otherwise. When the run exits it comes back with a pull request already opened, and other models stay parked for the occasional task that calls for unusual judgment. It runs when you ask it to, rather than on a timer.

## Before you install

Open the share link and read the instructions it carries before you add it. @farzyness shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
