## What it does

Reads your help center alongside whatever the product shipped in the last week, flags every page that no longer matches reality, and drafts the updated copy so documentation stops drifting. Writers get a targeted list instead of a stale-docs audit nobody has time to run by hand. It runs on a schedule rather than waiting to be asked.

## Before you install

Open the share link and read the instructions it carries before you add it. @DenisLabelle shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
