## What it does

Turns accepting a patch into a contest. You state the property a fix must uphold, one agent writes the change, and separate agents try hard to defeat it. The final gate reruns your real test suite on a scratch copy with no model in the loop, and any result that flips between identical reruns counts as a failure. It is built as a team of bots rather than a single one, so the roles stay separate.
