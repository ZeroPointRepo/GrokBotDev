## What it does

Sits in front of everything else you have built, so a request goes to one place instead of to six different assistants. It works out which specialist should handle each piece, passes the work along, and brings the result back to the same thread you started in. It runs when you ask it to, rather than on a timer. It is built as a team of bots rather than a single one, so the roles stay separate.
