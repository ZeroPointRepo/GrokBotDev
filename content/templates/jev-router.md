## What it does

A small, quick classification layer built on the Jev harness. It answers the cheap, constant questions in a pipeline: which branch an item goes down, how urgent it is, which label fits, and where it lands on a rubric. Calibration matters as much as speed, so a pricier model only runs when the question deserves it. It runs when you ask it to, rather than on a timer.
