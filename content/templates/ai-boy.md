## What it does

If you already pay for Claude Code or Codex, this lets you drive those coding sessions from a Grok conversation instead of living in a terminal. Kick off a task, watch it progress and wrap it up once it is done, all from one place. It is a convenience layer over tools you already have, not a substitute for them. It runs when you ask it to, rather than on a timer.
