## What it does

Every new capability starts life as an API that nothing else can reach yet. Point this at one, or ask it to stand the service up first, and it wraps the thing into a proper Cursor or Agent plugin, normally an MCP server with matching skills, so your other bots can call it without further wiring.

## Before you install

Open the share link and read the instructions it carries before you add it. @DenisLabelle shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
