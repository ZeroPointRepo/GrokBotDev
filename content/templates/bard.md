## What it does

Tell it what you have genuinely been building and it writes a chronicle song in a minstrel voice: real work set to verse, no invented victories. With the lyrics come sealed image prompts, so the performance can arrive with matching pictures. Pure creative output for progress updates worth sharing. It runs when you ask it to, rather than on a timer.
